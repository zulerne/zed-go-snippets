# Golang Snippets for Zed

Minimal Go snippets with short prefixes for Zed.

## Snippets

| Prefix | Expands to |
|--------|-----------|
| `pkgm` | `package main` + `func main()` |
| `im` | `import "..."` |
| `ims` | `import (...)` block |
| `co` | `const x = ...` |
| `cos` | `const (...)` block |
| `var` | `var x T` |
| `vars` | `var (...)` block |
| `st` | `type Name struct {}` |
| `iface` | `type Name interface {}` |
| `func` | Function declaration |
| `meth` | Method declaration |
| `init` | `func init()` |
| `main` | `func main()` |
| `if` | If statement |
| `ife` | If-else |
| `iferr` | `if err != nil {}` |
| `for` | For loop |
| `fori` | `for i := 0; i < n; i++ {}` |
| `forr` | `for k, v := range x {}` |
| `switch` | Switch statement |
| `sel` | Select statement |
| `case` | Case clause |
| `go` | `go func() {}()` |
| `gof` | `go f()` |
| `defer` | `defer func() {}()` |
| `deferf` | `defer f()` |
| `fp` | `fmt.Println()` |
| `ff` | `fmt.Printf()` |
| `fe` | `fmt.Errorf("...: %w", err)` |
| `sli` | `slog.Info()` |
| `sle` | `slog.Error()` |
| `tf` | Test function |
| `bf` | Benchmark function |
| `tdt` | Table-driven test |
| `ap` | `x = append(x, ...)` |
| `ret` | `return nil, err` |

## Install

Search "Golang Snippets" in Zed Extensions.
